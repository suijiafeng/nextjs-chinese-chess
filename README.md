# 中国象棋 (Chinese Chess / Xiangqi)

基于 **Next.js 15 + React 18** 的开源中国象棋游戏。

## 功能

- 🎮 人机对战（内置贪心+防守 AI）与双人对战
- ♻️ 完整规则：马腿、象眼、炮打隔子、将帅对脸、送将检测、将死/困毙判定
- ↩️ 悔棋、视角翻转、着法记录、被吃棋子展示
- 🎨 Canvas 绘制棋盘，无任何 UI 依赖

## 开发

```bash
npm install
npm run dev
```

打开 http://localhost:3000

## 构建

```bash
npm run build && npm start
```
