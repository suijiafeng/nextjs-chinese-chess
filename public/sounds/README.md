# 音效文件

把音频文件放在这里即可替换对应事件的合成音效，文件名固定、格式为 mp3：

| 文件名 | 触发时机 |
|---|---|
| start.mp3 | 开局 |
| move.mp3 | 普通落子 |
| capture.mp3 | 吃子 |
| check.mp3 | 将军 |
| win.mp3 | 获胜 |
| lose.mp3 | 败北 |
| draw.mp3 | 和棋 |
| select.mp3 | 选中棋子 |
| illegal.mp3 | 禁止长将、长捉等违规操作 |
| undo.mp3 | 悔棋 |
| bgm.mp3 | 背景音乐 |
| lowtime.mp3 | 剩余 60 秒、30 秒时 |
| tick.mp3 | 最后 10 秒，每秒一次 |
| timeout.mp3 | 超时判负 |

- 缺少某个文件时，该事件自动使用内置合成音效。
- 建议：落子类 0.3 秒以内、结果类 3 秒以内，音量相近，去掉开头静音。
- 修改文件后需刷新页面（浏览器可能缓存，必要时强制刷新）。

## 背景音乐

放入 `bgm.mp3` 将循环播放该文件（默认关闭，需点击顶部 ♬ 开启）；没有该文件时使用内置合成的五声音阶曲。
